# 原文保真

研迹是给研究生对着**原文**自学的。阅读区里的文章必须尽量原封不动；讲解、提问、高亮都是叠在原文上的工具，不是重排稿。

以后改抓取、清洗、样式、阅读器时，**先保证原文完整、排版不被改坏**，再考虑速度和“看起来更像论文”。

## 优先级

1. 正文、配图、图注、表格、行内公式图都在，且相对位置与源页一致。
2. 栏宽内完整可见：不裁切、不盖住、不撑出无法阅读的横向滚动（必要时整页可横向滚动，而不是把字和图裁掉）。
3. 在前两条满足之后，再优化抓取耗时、文件体积、视觉装饰。

## 正文

- 保留源页 DOM 结构，不要把公众号/新闻页/ar5iv 重排成统一的 12 点论文体例。
- 不要给全部子孙节点加 `white-space: normal !important`、`word-break: break-word`，以免打散原对齐和行内公式。
- 只删除脚本、追踪、二维码、真正的空占位（如 `viewBox="0 0 1 1"` 的布局 SVG）。不要删带图的节点。
- 文章 HTML 不要用 `$...$` 做整篇 KaTeX 扫描；微信里大量行内量是图片或源站已排好的。对话窗口里的讲解可以写公式。

## 图片

- 保持原始宽高比。栏宽不够时才缩小：`max-width: 100%; height: auto`。
- 禁止把所有 `img` 做成 `display: block` 或 `width: 100% !important`。行内公式图、图标必须仍在句子里。
- 不要去掉 `style`、`width`、`height`。若源站把样式放在 `data-original-style`，显示前写回 `style`。
- 抓取时先让懒加载图变成可访问地址，并把浏览器已下载的图缓存下来；完整优先于快。

## 浮层

- 知识点对话、侧栏不得挡住正文。浮层叠在右侧「基础知识点」栏内，或正文右侧留出不被遮挡的宽度。
- 原文高亮可以叠字，但不能改变字号、行距、图片尺寸。

## 改代码时对照

| 做法 | 允许 |
| --- | --- |
| 代理 `src`、补 `data-src` | 是 |
| 统一把图拉满栏宽 | 否 |
| 为去空白而 `display:none` 所有 `:empty`（含 `img`） | 否 |
| 对话里写 LaTeX | 是 |
| 把源 HTML 改写成 Markdown | 否 |

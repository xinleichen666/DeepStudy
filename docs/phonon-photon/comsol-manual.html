用 COMSOL 重做声光双环移频器仿真

对照稿：Resonant acousto-optic frequency shifting in a thin-film lithium niobate photonic molecule（2026-10-14）。按 COMSOL 6.2 / 6.3 英文界面书写。中文界面找同名节点。

每一步都是手动能做完的操作。论文里的数字是对照目标，不是你必须凑出来的答案。几何只要论文没写，就用组里的工艺截面，并记在最后的表里。

先看这一段再点 COMSOL。论文的 98.3%、6.7 µW 和加热器打开后的 96.4%，是耦合模常微分方程加参数抽样的结果，不是三维全波瞬态算出来的。COMSOL 在这里做两件事：第一部分用全局方程把这篇的算法重算一遍；第二到六部分用多物理场替换论文里假定的 ng、缝、声频、每伏频移和加热器温升。做完再代回全局方程。

不要跳过第一部分去画一颗三维双环，也不要在三维里跑 1000 次蒙特卡罗。

0　打开软件之前

需要这些模块：Wave Optics（光模式）、Structural Mechanics 与 AC/DC 或 MEMS（压电）、Heat Transfer（加热器）、基础模块里的 Global ODEs。缺 Wave Optics 时，光模式先不要用 RF 模块硬算。

界面固定为英文，单位制 SI。所有参数都写在 Global Definitions → Parameters 1，数值带方括号单位，例如 fa = 3.33[GHz]。不要混用 3.33 和 3.33e9。

1　全局方程：重现理想工作点

1.1　新建

  1. File → New → Model Wizard → 0D → Mathematics → ODE and DAE Interfaces → Global ODEs and DAEs → Time Dependent → Done。
  2. 在 Parameters 1 里逐行输入下面这张表。Ω、µ、γ、κi 都是角频率，所以带 2π 的量写成 2*pi*频率。
名称表达式含义
fa3.33[GHz]声频
Omega2*pi*fa角频率
muOmega/22µ = Ω，超模裂距等于声频
gamma2*pi*0.6[GHz]环 1 到总线的耦合
kappai2*pi*80.75[MHz]内禀损耗
Deltamu激光对准对称超模
domega2*pi*0.55[GHz]理想工作点的推动幅度
s0声光只推环 1。电光对照时改成 −1
ain1输入幅度，比值与它无关
G1(gamma+kappai)/2环 1 的总衰减
G2kappai/2环 2 的衰减
sqgsqrt(gamma)输入输出系数
t120[ns]只对最后 20 ns 做频谱

Definitions → Variables 1 增加一行：

Dt = Delta + domega*cos(Omega*t)

Dt 是环 1 的瞬时失谐。环 2 在 s = 0 时失谐保持为 Delta。

1.2　四个状态方程

光场写成 a1 = x1 + i y1，a2 = x2 + i y2。Global Equations 里每一行的残差是「时间导数减右端」，等于零。初值全部填 0。

名称残差 f = 0
x1x1t − (−G1*x1 + Dt*y1 + mu*y2 − sqg*ain)
y1y1t − (−G1*y1 − Dt*x1 − mu*x2)
x2x2t − (−G2*x2 + Delta*y2 + mu*y1)
y2y2t − (−G2*y2 − Delta*x2 − mu*x1)

论文式 (1) 的 −iµ a2 展开后，x1 的右端出现 +mu*y2，y1 的右端出现 −mu*x2。电光推挽以后把 Variables 里的 Dt 换成 Delta + domega*cos(Omega*t)，再给环 2 单独写 Dt2 = Delta − domega*cos(Omega*t)，并把上表 x2、y2 里的 Delta 换成 Dt2。第一部分先保持 s = 0。

1.3　最后 20 ns 的四个频率分量

出口 aout = ain + sqg·a1。再加八个全局方程，把 q = −1、0、+1、+2 的余弦、正弦分量积出来。名称里不能用减号，q = −1 写成 m1。

名称残差
m1rm1rt − (t>t1)*((ain+sqg*x1)*cos(Omega*t) − (sqg*y1)*sin(Omega*t))
m1im1it − (t>t1)*((sqg*y1)*cos(Omega*t) + (ain+sqg*x1)*sin(Omega*t))
c0rc0rt − (t>t1)*(ain+sqg*x1)
c0ic0it − (t>t1)*(sqg*y1)
c1rc1rt − (t>t1)*((ain+sqg*x1)*cos(Omega*t) + (sqg*y1)*sin(Omega*t))
c1ic1it − (t>t1)*((sqg*y1)*cos(Omega*t) − (ain+sqg*x1)*sin(Omega*t))
c2rc2rt − (t>t1)*((ain+sqg*x1)*cos(2*Omega*t) + (sqg*y1)*sin(2*Omega*t))
c2ic2it − (t>t1)*((sqg*y1)*cos(2*Omega*t) − (ain+sqg*x1)*sin(2*Omega*t))

Variables 里再加入：

Pm1 = m1r^2+m1i^2
P0 = c0r^2+c0i^2
P1 = c1r^2+c1i^2
P2 = c2r^2+c2i^2
eta = P1/(Pm1+P0+P1+P2)
dB0 = 10*log10(P0/P1)
dBm1 = 10*log10(Pm1/P1)
dB2 = 10*log10(P2/P1)

1.4　求解设置

  1. Study → Step 1 → Times：range(0, 3.75[ps], 40[ns])。3.33 GHz 的周期是 300 ps，3.75 ps 等于每周期 80 步，和论文一致。
  2. 打开 Time-Dependent Solver → Time Stepping。Steps taken by solver 选 Strict。Maximum step 填 3.75[ps]。Relative tolerance 填 1e-6。
  3. 默认的自由步长会跳过吉赫兹振荡，算出来的移频比没有意义。这一项不要省。
  4. Compute。Results 里对 x1 做 1D 时间图：前 2 ns 应有快速振荡并稳住。末时刻用 Derived Values → Global Evaluation 读 eta、dB0、dBm1、dB2。

对上了：eta 在 0.97–0.99；dBm1 约 −21 dB；dB0 约 −23 dB；dB2 约 −24 dB。论文的理想点是 98.3%、−21.2 dB、−23.2 dB、−23.6 dB。差几个百分点，来自时间窗和公差，可以进入下一部分。

对不上：eta 接近 0 或边带全无，先检查 Omega 是否写成了 2*pi*fa，以及时间步是否真的是 Strict。载波远大于信号，检查 Delta 是否等于 mu，以及 x1 方程里是 +mu*y2 不是 −mu*x2。

源功率在这一部分只做验算，不进微分方程。0.55 GHz 除以 21.3 GHz/V 得 26 mV。50 Ω 上峰值电压 V 的功率是 V^2/(2R) = 6.7 µW。这是 ξ = 1、叉指效率按邵 2019 约 50%、Qm 按 2000 的数。

2　光波导模式：自己的 ng

  1. 新模型，2D，Wave Optics → Electromagnetic Waves, Frequency Domain → Mode Analysis。
  2. 论文没有波导宽度和膜厚。有组里的截面就照画。没有的话，先用一个能算通的脊波导把流程走通：铌酸锂厚度 600 nm，刻蚀 300 nm，顶宽 1.2 µm，下面二氧化硅 2 µm，上面空气或 1 µm 二氧化硅。这组尺寸不是论文给定值，记录表里必须写「教学截面」或「PDK」。
  3. 材料搜索 Lithium Niobate，用单晶，不要用各向同性近似。新建 Rotated System：晶体 z（光轴）躺在晶片平面内，晶体 x 指向晶片法线。这是 X 切。转完以后检查：面内一个方向的折射率应接近非常光，法线方向接近寻常光。轴反了就改旋转，不要改模式结果去凑 2.3。
  4. 计算域左右和衬底底边用散射边界或完美匹配层。脊内网格最大单元约 80 nm。
  5. Mode Analysis：频率 193.4[THz]，搜索的有效折射率中心 2，模式数 20。取能量集中在脊里、neff 最高的那个导模，记下 neff。
  6. 同样的网格再算 193.1[THz] 和 193.7[THz]。
ng = neff − f · (neff2 − neff1) / (f2 − f1)
f 取 193.4 THz，neff 取这一次的结果，下标 1、2 是 193.1 与 193.7 THz。

对上了：ng 落在大约 2.1–2.4。论文写 2.3 是假定。用你的 ng，不要改输入去凑 2.3。以后式 (2) 里的环长频率因子全部用这个 ng。

3　双波导：把裂距调到 3.33 GHz

仍用二维截面，画两根与第二部分相同的脊，间隙 g，共用一个计算域。Mode Analysis 会给出偶模和奇模两个 neff。裂距来自耦合段上多走的相位，再除以整圈时间：

Δf = (Δneff · Lc / λ) · c / (ng · Lring)
Lring = 0.667[mm]，λ = c/193.4[THz]，Δneff = neff偶 − neff奇
c / (ng · Lring) 是这颗环的自由光谱区。ng = 2.3 时大约 196 GHz。

这个 Δf 就是论文里的超模裂距 2µ/(2π)。目标是 3.33 GHz。

  1. 先固定耦合长度 Lc = 40[µm]，扫 g = 0.3、0.4、0.5、0.6、0.8 µm。
  2. 每个 g 记录 Δneff 和 Δf。
  3. 论文的可调耦合器要求最大裂距大约 3.33×√2 = 4.71 GHz，加热到一半时才是 3.33 GHz。选一组 (g, Lc)，使最大 Δf 接近 4.71 GHz。冷态工作点由第六部分的加热相位决定，不在这一步用死间隙凑 3.33。
  4. 间隙误差以后按论文的衰减长度换算，不需要再跑模式：5 nm 对应大约 3.33 GHz × (5/150) = 111 MHz。论文写的是约 114 MHz，同一量级。

对上了：有一条连续的 Δf(g) 曲线，并且存在一组尺寸使最大裂距在 4–5 GHz。对不上时先查两根波导是否共用材料坐标系，以及 Lc 是否只乘在耦合段上、没有乘整圈。

4　叉指周期：把声频调到 3.33 GHz

  1. 新模型，2D。Solid Mechanics + Electrostatics，Multiphysics 加 Piezoelectric Effect。Study 用 Eigenfrequency。
  2. 只画一个周期，不要画整圈。周期宽度 p 是一个正指加一个负指的总宽，大约 1 µm 量级；电极厚度没有工艺数时先用 100 nm 铝，铌酸锂厚度与第二部分相同。左右两边用 Periodic Condition。衬底底边固定或加低反射层。这块板是悬空层时，底边不要固定死在厚硅上。
  3. 一个电极 Terminal 1 V，另一个 Ground。晶体轴与第二部分相同。
  4. 搜索 3.33 GHz 附近的本征频率。扫 p，直到有一个能量集中在铌酸锂表层的模式落在 3.33 GHz ± 50 MHz。
  5. 记下此时的 p、电极宽、以及这个模式的频率和它与相邻模式的间隔。

这一步给出的是掩模上的指间距，不是论文里的 Qm。Qm = 2000 或 3600 来自整颗谐振器的锚点损耗，二维单周期看不出来。Qm 先沿用论文：计算用 2000，保守功率用 1570，测到过的上限是 3600。不要把二维本征值的虚部当成 Qm。

5　光弹：每伏能把共振推多远

电极上加的是第四部分那个 1 V 的解。应变改变折射率，模式的 neff 跟着变，再用论文式 (2) 换成整颗环的频率移动。

  1. 在光学模型里把第四部分的应变导进来，或把应变分量做成参数。优先用材料库里铌酸锂的光弹系数把应变写成 Δε。库里没有系数时，先只做「应变已换成 Δn」的流程，系数表单独注明出处，不要默默使用一组记不清符号的数。
  2. 对加应变和不加应变各算一次第二部分的导模，得到 Δneff。
  3. 100 µm 作用长度上的相位，以及整圈造成的频率移动：
Δφ = 2*pi/λ · Δneff · La ， La = 100[µm]
δf = Δφ · c / (2*pi · ng · Lring)

这就是式 (2)。δf 的单位是 Hz，除以电极电压 1 V，就是你的每伏频移。

ξ = （你的 δf，单位 GHz/V） / 21.3

对上了：ξ 在 0.3–2 之间都可以往下做。论文把 21.3 GHz/V 定为 ξ = 1，那是邵 2019 直波导的外推，不是你这个截面的测量。ξ 小于 0.5 时，第五部分的功率表会升到几百微瓦以上，仍可以记录，但要在第七部分显式写出来。

若 δf 是在电极 1 V 下直接算的，它已经包含模型里的机电耦合。后面的源功率用 P = V²/(2×50 Ω)，不要再乘叉指效率，否则算重了。叉指效率只在你故意把结果归一化到邵的 21.3 GHz/V 时才另乘。

6　加热器：相位和串扰

  1. 2D 截面。两根波导，间距用第三部分选定的 g。一臂外侧放金属条，离脊 1–2 µm，不要压在光模上。材料用工艺里的加热金属；没有就先用金，厚度 100 nm，并写进记录表。
  2. Electric Currents 加 Heat Transfer in Solids，稳态。金属两端加电压，扫电压。用面积分 J·E 得到热功率 P。
  3. 读三个温度：加热臂中心、环 1 波导中心、环 2 波导中心。环境温度 293 K，底边设为散热边界；散热系数没有工艺数时先用自然对流的量级并注明，这是本步最大的不确定量。
  4. 相位用你第二部分的 ng 所对应的热光系数路径来算。论文用 dne/dT = 3.34e−5 /K：
Δφ = 2*pi/λ · (dne/dT) · (T臂 − T环境) · Lheater
Pπ = 使 Δφ = π 的功率

两环频差用温度差乘 df/dT。论文的热光一项大约 2.8 GHz/K；加上体膨胀大约 5.6 GHz/K。更干净的做法是把第二部分的模式在两个温度下再算一次，用你自己的 df/dT。

论文里的 44.4 mW 是别人约 1 mm 金加热臂的数，2 mK / 3 mK 是假定的串扰，都不是你要去凑的目标。你的 Pπ 和两环温差才写进第七部分。20 mW 附近若两环温差已经到几十毫开，就不要再引用 96.4% 的成品率。

7　把你的数代回全局方程

  1. 回到第一部分那个文件。ng 只影响你怎么把 δf 换成电压，不改微分方程里的 gamma。
  2. 对 domega 做参数扫描：2*pi*range(0.2,0.05,1.0)[GHz]。每个点读 eta。取 eta 最大的那个 δf，记为 δfopt。理想参数下它应靠近 0.55 GHz。
  3. 电压和源功率：
V = δfopt / (21.3[GHz/V] · ξ)
P = V^2 / (2*50[ohm])

只有当你的 ξ 是相对邵的 21.3 定义、并且邵的校准含大约 50% 叉指效率和 Qm = 2000 时，才另外乘：

P源 = P · (0.5/ηIDT) · (2000/Qm)

ηIDT 取 0.1 和 0.5 各算一次。Qm 取 1570、2000、3600 各算一次。ξ = 0.3、0.5、1、2 再各算一次。论文在 ξ = 0.5、ηIDT = 10%、Qm = 1570 时是 172 µW；ξ = 1 时同一效率和 Q 是 43 µW。你的 ξ 来自第五部分之后，这张表会整体乘 1/ξ²，不必和 172 重合。

这一步的结果才是你自己的工作点。记录 η、dBm1、dB0、V 和 P源。理想参数复现的 98.3% 和 6.7 µW 留在第一页，当作软件操作是否正确的检查，不当作器件预测。

8　公差：仍在全局方程里扫

下面每一项都只改一个参数，几何不再重画。

扫描怎么改参数论文里用来对照的行为
内禀损耗kappai 乘 1、2、5乘 2 时移频比仍高，插损变大；乘 5 时移频比明显下降

插损用出口各频率分量的总功率比输入。论文理想插损 2.5 dB；κi×2 的中位插损 4.72 dB。你的 kappai 没改时，应靠近 2.5 dB，而不是靠近 4.72 dB。

9　热声子和 HOM：不要建三维模型

热声子数是公式，不是场仿真。f = 3.33 GHz、T = 300 K 时，

nth = 1 / (exp(h·f/(kB·T)) − 1) = 1877

论文在工作点给出相干声子数约 1.75×10¹¹，所以 nth/Ncoh ≈ 1.1×10⁻⁸。自发散射上界 nth·C0 ≈ 8.0×10⁻⁶，用的是 g0/2π = 1.1 kHz 和这颗环的光学线宽。这两行写进记录表即可。

HOM 用第一部分的文件做参数扫描：Delta 在工作点两侧各取若干点，每个点记录 c1r 和 c1i，这就是 q = +1 通道的复传递函数 H。点数按论文取 41 个，范围盖住光子频谱的 ±4 个标准差。可见度是论文式 (3) 对这 41 个复数的求和，在表格里算。不要为 HOM 再画器件。不加滤波时，可见度应接近你第七部分的 eta；10 MHz 光子、滤波之后 1−V 很小，那是线宽 0.6 GHz 的腔对窄谱几乎是平的，不是新的器件结果。

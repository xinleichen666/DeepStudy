按 2026-10-12 文献简报判定。平台是薄膜铌酸锂；这一阶段做仿真和台面，不做自有流片。

判定日期 2026-10-12。器件数字只取简报里已核对的公开文献。热声子占据由声频和温度算出，表内标明，不写成实测噪声。

结论。做两个方向，先做方向一，方向二接在同一套参数和同一套台面光路后面。方向一交出移频保真度的噪声分区；方向二交出同一路声驱动上的可编程声相位，以及加热对移频和相位的联合传递。两篇都投 Optics Express、Applied Physics Letters 或同等的仿真加台面刊物。没有流片数据的器件文，不投 Nature 子刊。

1　选择依据

简报给出的工作条件是：薄膜铌酸锂（可对照铌酸锂-on-蓝宝石和氮化镓-on-蓝宝石）；仿真用 COMSOL、耦合模和 Monte-Carlo；台面用商用声光调制器、光纤、商用薄膜铌酸锂调制器、SPDC、HOM 和光谱仪；组内已有声学马赫–曾德尔加热调的 COMSOL。激光直写不承担声光主线。

下面四个题目不立为方向。

题目依据
片上微瓦级声学光子分子频移器，并把转换效率做到接近电光 Zhu 等，arXiv:2511.22585，已经在铌酸锂-on-蓝宝石上做了声驱动光子分子实验。效率要对标 Hu 等，Nature 2021（28.2 GHz 频移，文中效率约 98.7%，常见引用功率约 96 mW；带宽在数 GHz 量级）。简报写明：阻抗匹配之后，声学在功率上的优势可能消失。这条线还要求自有或合作流片。
片上布里渊量子存储 简报记载掺铒薄膜铌酸锂原子频率梳已存电信单光子级脉冲，存储时间 >1 µs，最多 20 个时间模，接收带宽最高 2.2 GHz。超过这一指标的片上布里渊量子存储，简报列为需要流片或强合作。光纤受激布里渊只保留为方向二的经典延迟类比。
以「声光频移比电光更省功率」做主结论 Shao 等，Opt. Express 2020：片上频移效率 3.5%（30 dBm）。Hu 等的约 99% 是电光双环的转换效率。Qiu 等，Opt. Lett. 2025，摘要报道 serrodyne 电光频移效率 >98.8%（摘要未核全文）。两个百分比不是同一个量。只比效率时，电光是天花板。
只复现氮化镓声子电路，或者做声光束偏转雷达 Xu 等，arXiv:2510.26596，平台是氮化镓-on-蓝宝石，文中没有声光接口；它的热声相移 4.03 rad/W（100 µm）只做方向二的锚点。Yu 等，Nat. Commun. 2026，共振增强声光束偏转效率最高 26%、视场 18°，是自由空间雷达，不进入频移–声相位这条线。

2　方向一：移频噪声账本与移频 HOM

2.1　摘要里允许出现的句子

用公开标定的声光参数，把三类器件的移频噪声拆开，给出室温下频率仓 HOM 可见度的上限；光纤声光调制器这一支，用 SPDC 移频 HOM 测到。

2.2　三类器件分三本账

三类器件的头条数字不能放进同一张「效率」柱里比较。方向一的实验只对第一类。

甲　行波布拉格声光频移器 — 台面的对标对象

Shao 等，Opt. Express 28, 23728 (2020)。薄膜铌酸锂上叉指换能器激发瑞利波，斯托克斯与反斯托克斯从空间端口分开。频移约 2.9–3 GHz；载波抑制 >30 dB（斯托克斯 31 dB，反斯托克斯 33 dB）；杂散边带抑制 >40 dB；片上频移效率 3.5%（30 dBm）；单叉指的微波到声效率约 31%；射频 3 dB 带宽约 70 MHz；光纤到光纤插入损耗约 −15 dB。

这是相干驱动的经典光栅。商用光纤 AOM 与它同类：强射频驱动，边带在频率上分开。方向一的 HOM 数据点只画在这一类上。

乙　共振声光微波–光转换 — 只做标定，不承担频率仓主结果

Shao 等，Optica 6, 1498 (2019)。悬空 X 切薄膜铌酸锂。马赫–曾德尔：作用区 100 µm，声模约 3.33 GHz，声学 Q 约 3600，单臂 Vπ = 4.6 V，VπL ≈ 0.045 V·cm，转换带宽约 1 MHz。跑道环：光学 Q > 2×106，有效 Vπ = 0.77 V，g0 ~ 1.1 kHz（声模约 2.17 GHz），1 mW 光功率下光子数转换效率 0.0017%，单光子协同率 C0 ≈ 4×10−8。叉指到声模耦合效率最高约 50%。

这些数字用来锁定 g0、Vπ 和 Q。光子数转换效率停在 0.0017% 这一公开结果上，本文不把该器件写成单光子频率仓频移器。

丙　后向布里渊强耦合 — 算自发散射上限，并标明换算是假设

Zhu 等，arXiv:2511.22585。铌酸锂-on-蓝宝石耦合双微环，声频 Ω/2π ~ 8.54 GHz，β/√Pa = 2π×1.33 GHz/√mW，C/Pa = 2.46 mW−1（Pa = 2.5 mW 时 C = 6.2）。声功率约 0.6 mW 时可见强耦合劈裂。动态布拉格镜反射率 24%（Pa = 6.3 mW）。超模线宽 κ/2π ≈ 0.93 GHz 与 0.69 GHz。文中功率是声功率。文中没有单端口频移效率。

Xu 等，arXiv:2509.01940。同类材料上的环内后向布里渊：G2 = α Pa，α = 1774±171 GHz2/W（8.533 GHz），射频到声约 10%，κ0/2π ≈ 0.32 GHz，5.7 dBm 声功率下隔离 45 dB。

方向一用 α、C 和 κ 估计自发布里渊进入信号模的上限。从「动态布拉格镜反射率」换算到「单边带移频保真度」在图注里写成模型假设。Zhu 的实验本身没有给出这个保真度。

10 mK 时，3 GHz 的 hf/kBT ≈ 14，nth 降到远小于 1。Weaver 等，Nat. Nanotechnol. 2024（效率约 0.9%，带宽 14.8 MHz）和 Jiang 等，arXiv:2210.10739（连续转换效率约 5%，热噪声 <2 个微波光子）走的是低温换能。方向一的台面在室温。4 K 一列放进表里，是为了标明：把 Shao 2019 的器件放进液氦，nth 仍是数十，量子换能并不自动成立。

账本因此分成三件事，分开算。

  • 甲类，相干驱动光栅。移频场可以是经典相干态。热声子进入自发散射本底和相位抖动。可见度对残余载波的那一支，用光纤 AOM 直接测。
  • 乙类，共振换能。公开数字是 nth ~ 103（室温、3 GHz）和 C0 ~ 10−8。这一类提供 Vπ 与 g0 的标定，不提供频率仓保真度的主曲线。
  • 丙类，布里渊强耦合。经典协同率在毫瓦声功率已经大于 1。要单算的是自发散射进信号频率仓的概率，以及光学线宽已经到 0.3–0.9 GHz 时，频率仓是否还分得开。

2.4　台面怎么测

仪器：商用光纤 AOM、SPDC、HOM、光谱仪。AOM 的驱动频率、射频功率、移频效率、载波抑制和边带抑制全部自己测，不把 Shao 的 3.5% 填进实验栏。

光路：SPDC 的一路经过 AOM，与另一路做 HOM。扫载波抑制，得到可见度曲线。这条曲线核对账本里「残余载波 → 可见度」。

图注里写明边界：商用光纤 AOM 的移频由型号决定，常见型号在 102 MHz 量级，与 Shao 2020 的约 3 GHz 薄膜声模不是同一个振子。室温热声子占据不由这次 HOM 测出。GHz、nth 和片上 g0 的曲线是外推，实验点只落在 AOM 那一支。

插入损耗进计数率。Shao 2020 光纤到光纤约 −15 dB 用来估计片上符合计数会下降多少，不写进可见度上限。

2.6　审稿人那一句，以及必须写上的差分

问：Hu 的电光频移效率约 99%，Qiu 的 serrodyne 摘要效率 >98.8%，为什么还做声光移频。

答：电光移频没有这条 GHz 声子通道上的自发散射和热声子本底。本文计算的是声光移频的保真度上限。只比较转换效率时，电光仍是天花板，本文不给出功率胜负。

文中引用 Zhu 等，arXiv:2511.22585，并写明几何差别：本文做噪声账本和单路移频可见度，不提出新的双环光子分子。Shao 的 3.5% 与 Hu 的约 99% 分列。若正文出现功率比较，先写阻抗匹配，并接受匹配之后声学功率优势可以不存在。

3　方向二：同一路声驱动上的移频与声相位

3.1　摘要里允许出现的句子

在已有声学马赫–曾德尔模型上加入光弹重叠，用 Xu 的热声相移和 Shao 的 VπL 做锚，给出同一路声驱动下移频强度与声相位的联合误差传递；误差公式用商用 AOM 加光纤相位的台面核对。

3.2　第一道关：先对上热声相移的量级

现有 COMSOL 先在它本来的材料和几何上，算出能与 Xu 等，arXiv:2510.26596，的 4.03 rad/W（100 µm 长相移器）放在同一量级的热声相移。这一步对不上，方向二停在模型标定：不加光波导，不写器件指标。

对上之后，再换薄膜铌酸锂或铌酸锂-on-蓝宝石的弹性、压电和光弹常数。每一项材料常数单独列表，给出出处。换材料之后的相移和频移强度标成「计算」。旁边放两条实测参考，供读者看计算点落在哪里：

  • Shao 等，Optica 2019：悬空马赫–曾德尔，VπL ≈ 0.045 V·cm。
  • 简报中的非悬空对照：VπL ≈ 1.004 V·cm，0.842 GHz，射频 3 dB 带宽 132.5 MHz（Ni / Bhave / Xu，arXiv:2606.05337）。简报标明该条来自既有核对表，本次未重读全文。正文沿用这个标注。

文章不声称计算值超过这两条实测。

3.3　模型里有什么

一条声学生总线，一个热声相位臂（组内马赫–曾德尔已有的部分），一段与单根光波导重叠的声光作用区。光波导只取一根，做行波相位调制或频移的重叠积分。结构里不画耦合双环，以免和 Zhu 的光子分子落在同一几何上。

输出两个计算量，都是叉指功率和热调功率的函数。

  • 声相位 φ（弧度），以及由该模声速和声程得到的群延迟。声速取 COMSOL 的模速度，正文写明晶向和模族。
  • 声光耦合强度，写成可以和 Shao 的 Vπ 或 g0 并列表的形式。

两个旋钮都会加热。加热改变声速，也改变光程或相位匹配。传递函数的输出是移频保真度（含载波抑制的退化）和干涉相位误差。本文里的「传感」就是这个干涉相位还能分辨多小的变化。简报里的铌酸锂微环压力、光声气体传感卡片没有核对到唯一全文，不写进模型。

群延迟的含义是可编程声相位对应的延迟，数值由模速度决定。掺铒薄膜铌酸锂原子频率梳的 >1 µs 和最多 20 个时间模是稀土离子存储，正文把两条通道分节描述，不把声延迟写成量子存储指标。

3.4　台面怎么测

商用 AOM 提供移频。光纤延迟线或热调光纤马赫–曾德尔提供独立的相位旋钮。两个旋钮分开扫，记录干涉读出。实验核对的是误差公式：移频支路的残余载波和相位支路的漂移怎样同时进入可见度或条纹位移。

这次台面不核对铌酸锂里的光弹重叠积分。重叠积分只在仿真一节。正文不出现「片上已经同时集成频移与声延迟」。

问：移频交给电光，声子只做存储，为什么绑在同一个驱动上。

答：这篇的声子通道同时给出光频移和可编程声相位。电光频移器没有这路机械相位。文章的结果是这两项的联合误差。

3.7　和方向一怎么接

方向一给出可见度对残余载波和自发散射的上限。方向二给出热调功率把相位匹配和载波抑制推离这个上限的速度。两篇用同一张参数表。方向二的光路在方向一的 AOM 和 HOM 上增加光纤相位臂。

非互易隔离先不写进主结果。Xu 的 α = 1774±171 GHz2/W 和 45 dB 隔离留在参数表里，作为以后「移频之后再隔离」的输入。那一步仍然不把隔离器当成现在要做的器件。

4　工作顺序

顺序由依赖关系决定，不靠流片节点。

  1. 先做一张共用参数表。每一行标明「文献实测」或「本文计算」。文献实测旁注篇名；简报标明未重读全文的，表内保留这个注。
  2. 方向一：写出三类器件的噪声项，锁到第 2 节的公开数字；搭 AOM + SPDC + HOM，先测可见度对载波抑制。
  3. 方向二的关口：现有声学马赫–曾德尔 COMSOL 对 4.03 rad/W 的量级。对不上就停。
  4. 关口通过后，换铌酸锂材料常数，加单根光波导的光弹重叠，输出联合传递函数。
  5. 在方向一的光路上加光纤相位臂，核对传递函数。
  6. 两篇各自成文。代工流片放到两篇的参数表和误差公式都写完之后再考虑。

7　写的时候放在首页的边界

  • 参数表分成「文献实测」和「本文计算」两栏。
  • 引用 Zhu 等 arXiv:2511.22585。正文几何不重复耦合双环光子分子。
  • Shao 2020 的 3.5%（30 dBm，行波声光）与 Hu 2021 的约 99%（电光双环）分列。
  • 台面数据与片上外推用两种图例。外推曲线的图注写明输入参数和假设。
